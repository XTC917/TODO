隐私政策

最近更新：2026-08-13

JUJU Schedule（下称「JUJU」）是一款个人日程与 Todo 应用。我们希望用尽量短的文字，把数据怎么处理说清楚。

我们收集哪些信息？

JUJU 目前不要求注册账号，也不提供云同步。你在应用里创建的日程、待办、提醒、专注记录和统计数据，默认保存在你自己的设备上。

本网站本身不设账号系统，也不会把你的日程数据上传到我们的服务器——因为官网是纯静态页面，没有后端数据库。

本地存储

应用数据存储在设备本地。卸载应用或清除应用数据，可能会删除这些内容。请在需要时使用应用内的导出功能自行备份。

导入 / 导出

你可以把数据导出为备份文件，并在其他设备上导入。备份文件由你自己保存和传输，JUJU 不会自动把备份上传到云端。

通知与系统权限

如果你开启提醒或专注通知，系统可能会向你申请通知、精确闹钟、自启动或电池优化相关权限。这些权限用于在设备本地按时提醒，不是为了收集你的内容。

用户反馈

如果你通过「用户反馈」提交意见，表单由第三方表单服务（金数据）托管。你在表单里填写的内容会提交给该服务，以便我们查看反馈。请不要在反馈里填写不必要的个人敏感信息。

本网站

官网可能在你的浏览器里记住语言偏好（localStorage）。我们没有在官网上接入统计或广告追踪脚本。

以后如果有变化

如果以后增加账号、云同步或其他会处理个人数据的功能，我们会更新本页说明。当前版本请以「本地存储、无需注册、无云同步」为准。

JUJU Schedule (“JUJU”) is a personal schedule and todo app. This page explains how data is handled, in plain language.

What information do we collect?

JUJU currently does not require an account and does not offer cloud sync. Schedules, todos, reminders, focus records, and statistics you create are stored on your device by default.

This website has no accounts and no backend database, so it does not upload your schedule data to our servers.

Local storage

App data lives on your device. Uninstalling the app or clearing app data may delete it. Please export a backup when you need one.

Import / export

You can export a backup file and import it on another device. You keep and transfer that file yourself. JUJU does not automatically upload backups to the cloud.

Notifications and system permissions

If you enable reminders or focus notifications, the system may ask for notification, exact alarm, autostart, or battery-related permissions. These are used to remind you on the device, not to collect your content.

Feedback

The feedback form is hosted by a third-party form service. Whatever you submit there is sent to that service so we can read it. Please avoid sharing sensitive personal information in feedback.

This website

The site may remember your language preference in the browser (localStorage). We do not include analytics or advertising trackers on this site.

If this changes

If accounts, cloud sync, or other personal-data features are added later, this page will be updated. For now, JUJU is local-first: no sign-up, no cloud sync.
